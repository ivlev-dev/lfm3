# Paged flash attention (HVX-слой, LFM3)

Файлы: `attn_flash.c`, `kvcache.c`, `attn_main.c`, `attn_build.sh`.
Комментариев в коде нет, поэтому раскладки и семантика зафиксированы здесь.

## Арена и таблица страниц

* `kv_pages` — массив физических страниц: `page_bytes = kv_heads * head_bytes`.
  Внутри страницы головы лежат подряд: голова `h` начинается с
  `kv_pages + phys * page_bytes + h * head_bytes`.
* `tbl[lp]` — физический номер страницы для логической страницы `lp = pos >> 5`.
  Токен внутри страницы: `pos & 31`. `head_bytes` для kvarn —
  `lfm_kvarn_head_bytes(fmt)`, для `LFM_KV_F16` — `2 * 32 * 128 * 2`.
* Одна kvarn-голова хранит K в полях `kcode/ka/kc` и V в полях
  `vcode/vb/vbz/vc`. `lfm_kvarn_commit_work` кодирует один тензор сразу в обе
  половины, поэтому `lfm_hvx_kvcache_commit` вызывает кодировщик дважды: K
  пишется в страницу целиком, затем V-половина копируется поверх. K- и
  V-половины побайтово совпадают с отдельными вызовами кодека.

## Раскладка Q и выхода

`q_rot` и `out_rot`: `[ntok][n_heads][128]`, то есть token-major, как выход
q-проекции. Q приходит повёрнутым (`R`), выход тоже в повёрнутом базисе;
обратный поворот делает вызывающий.

## Семантика

* `start` — абсолютная позиция первого query-токена: запрос `t` находится в
  позиции `start + t`.
* causal: ключи `j <= pos`; окно — `j >= lfm_window_start(pos, window)`,
  `window = 0` — полный контекст.
* GQA: `group = n_heads / kv_heads`, запросная голова `h` читает KV-голову
  `kh = h / group` (подряд идущие группы).
* `scratch` — не менее `2 * 32 * 128 = 8192` float: K-блок и V-блок страницы.
  Матрица scores не материализуется: KV читается страницами, online-softmax
  (f32) идёт по ключам, страницы декодируются один раз на `(query, kv_head)`.
* `fmt = LFM_KV_F16` использует раскладку головы `[K: 32x128 f16][V: 32x128 f16]`
  (внешнего спека на неё нет; путь нужен только для полноты enum).

## Сборка

```sh
cd myelin/dsp/hvx
./attn_build.sh                                      # host: cc + запуск теста
HEXAGON_SDK_ROOT=/opt/hexagon-sdk-6.7.0.0 ./attn_build.sh   # + DSP-объекты
```

Хостовый тест проверяет побайтовую раскладку страницы, cos против CPU-f32
эталона на декодированных K/V (k4v4 >= 0.999, k4v2 >= 0.995), обрезку окна,
`start != 0`, decode (ntok = 1) и две последовательности с разными таблицами
в общей арене.
