# Сводные замеры

Все цифры с условиями и источником. Метка: **измерено** / **оценка** /
**в работе** / **нет данных**. Даты — по времени артефактов.

## 1. Стенды

| стенд | что | условия |
|---|---|---|
| Телефон | Snapdragon 888, CDSP v68 | 1.42 ГГц, unsigned PD, HVX 128 B, 2 контекста, VTCM 4 МБ |
| APU (для сравнения) | AMD Radeon Vega 8 (Raven), OpenCL/Rusticl | 8 CU, подгруппа 64, fp16, UMA DDR4-2400, auto-DPM 928–1183 МГц |
| Host | x86_64 | только симуляции (`conv_sim`), не perf-стенд |

APU-цифры — это **модель целиком** (prefill/decode tok/s) либо синтетический
`dot-rate`; напрямую с временем одного DSP-ядра они не сопоставимы. Сравнивать
можно только GMAC/s `dot-rate` с GMAC/s ядра, и это помечено.

## 3. FFN-слой (телефон)

Один FastRPC-вызов: gate+up 2×7680×2048 → SiLU → down 2048×7680, int4
резидентно. Источник: `gemv/README.md`, `ffn_test`, `ffn_raw.txt`, 21–22.11.2026.

| конфигурация | время | метка |
|---|---|---|
| 1 HVX-контекст | **3.11 мс** | измерено |
| 2 HVX-контекста | **~1.98 мс** | измерено |
| 2 контекста, отдельные прогоны | 1.23–1.47 мс | измерено (`ffn_raw.txt`) |
| разбивка 1 ctx | gate 0.66, up 0.64, SiLU 0.82, down 0.68, pack 0.08 мс | измерено |
| QNN-эквивалент (3 × 1.37) | 4.11 мс | измерено (QNN) |
| корректность | bit-exact, 0 mismatches | измерено |

Примечание: диапазон 1.38–1.59 мс из постановки задачи в артефактах не
воспроизводится; подтверждённый разброс — 1.2–2.0 мс в зависимости от прогона
и загрузки стенда.

SiLU: LUT-1025 + lerp, max|err| **3.0e-5** (Q16) — измерено на хосте.
